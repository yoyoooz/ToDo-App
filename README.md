# ✅ Todo App

A clean and interactive **Todo List Application** built with **HTML, CSS, and JavaScript**.  
Easily add, manage, and track your daily tasks — all in a simple and minimal interface.

🌐 Live Demo: [View here](https://yoyoooz.github.io/ToDo-App/)

---

## 🧠 Overview
This **Todo App** helps users stay organized by allowing them to add, complete, and filter tasks.  
It’s a beginner-friendly project demonstrating DOM manipulation, event handling, and local storage management.

---

## ✨ Features
- ➕ Add new tasks instantly  
- ✅ Mark tasks as completed or active  
- 🔍 Filter tasks by *All*, *Active*, or *Completed*  
- 🗑️ Clear completed tasks with one click  
- 💾 Saves your todos using **localStorage**  
- 🗓️ Displays the current date dynamically  
- 💡 Responsive and minimal design
